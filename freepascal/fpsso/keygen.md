# คู่มือการสร้าง License Key (keygen)

โปรแกรม `keygen` เป็นเครื่องมือสำหรับผู้พัฒนา (Developer) ใช้ในการสร้างไฟล์ `license.key` เพื่ออนุญาตให้ลูกค้านำโปรแกรม `fpsso` ไปใช้งานได้ตามเงื่อนไขที่กำหนด

> **คำเตือนสำคัญ**: ห้ามนำโปรแกรม `keygen` หรือซอร์สโค้ด `keygen.lpr` ไปติดตั้งที่เครื่องของลูกค้าโดยเด็ดขาด ให้ออกไฟล์ `license.key` จากเครื่องของนักพัฒนาแล้วส่งให้ลูกค้าเฉพาะไฟล์ `.key` เท่านั้น

---

## ขั้นตอนการสร้าง License Key ให้ลูกค้า

### 1. ขอ Machine ID จากลูกค้า
ระบบ License ของเราผูกติดกับฮาร์ดแวร์ของเครื่องเซิร์ฟเวอร์ (Hardware Binding)
ให้คุณบอกลูกค้าว่า **"รบกวนรันคำสั่งด้านล่างนี้ที่เซิร์ฟเวอร์ แล้วก๊อปปี้รหัสที่ได้ส่งมาให้หน่อยครับ"**

```bash
./fpsso --hwid
```

ลูกค้าจะเห็นผลลัพธ์หน้าตาประมาณนี้:
```text
=== fpsso Machine ID ===
Machine ID: f4892daed9d445fb8eb4b85e45f76bc8
```
ให้ลูกค้านำค่า `f4892daed9d445fb8eb4b85e45f76bc8` ส่งมาให้คุณ

---

### 2. รันโปรแกรม keygen ที่เครื่องของคุณ
เปิด Terminal ที่เครื่องของคุณ (เครื่องที่มีไฟล์โปรแกรม keygen) แล้วพิมพ์คำสั่ง:

```bash
./keygen
```

โปรแกรมจะเข้าสู่โหมดตอบโต้ (Interactive) ให้คุณกรอกข้อมูลดังต่อไปนี้:

1. **Machine ID ของลูกค้า:** `(นำค่าที่ลูกค้าส่งมาวางลงไป แล้วกด Enter)`
2. **ชื่อหน่วยงาน:** `(เช่น โรงพยาบาลตัวอย่าง หรือ ชื่อลูกค้า)`
3. **วันหมดอายุ:** `(รูปแบบ YYYY-MM-DD เช่น 2027-12-31 หากเป็นไลเซนส์ตลอดชีพ Lifetime ไม่หมดอายุ ให้กด Enter ผ่านได้เลย)`
4. **จำนวนผู้ใช้สูงสุด:** `(ใส่ตัวเลข เช่น 100, 500 หรือใส่ 0 ถ้าไม่จำกัดจำนวนผู้ใช้)`
5. **ฟีเจอร์:** `(ระบุ all เพื่อเปิดทุกฟีเจอร์ หรือ basic หากมีการล็อกฟีเจอร์ในอนาคต)`

**ตัวอย่างการกรอกข้อมูล:**
```text
============================================
      fpsso License Key Generator
============================================

Machine ID ของลูกค้า: f4892daed9d445fb8eb4b85e45f76bc8
ชื่อหน่วยงาน: โรงพยาบาลตัวอย่าง
วันหมดอายุ (YYYY-MM-DD, ว่าง=ไม่หมดอายุ): 2027-12-31
จำนวนผู้ใช้สูงสุด (0=ไม่จำกัด): 0
ฟีเจอร์ (all/basic) [all]: all

License Key สร้างสำเร็จ!
  Serial    : FPSSO-2026-8296-B2C1-8A63
  Licensee  : โรงพยาบาลตัวอย่าง
  Machine ID: f4892daed9d445fb8eb4b85e45f76bc8
  Issued    : 2026-08-11
  Expiry    : 2027-12-31
  Max Users : 0
  Features  : all

ไฟล์ถูกบันทึกที่: license.key
กรุณาส่งไฟล์นี้ให้ลูกค้า
```

---

### 3. ส่งไฟล์ license.key ให้ลูกค้า
เมื่อสร้างเสร็จ คุณจะได้ไฟล์ `license.key` โผล่ขึ้นมาในโฟลเดอร์เดียวกัน
- ให้ส่งไฟล์ `license.key` นี้ไปให้ลูกค้า
- บอกลูกค้าว่าให้นำไฟล์นี้ไปวางไว้ **ในโฟลเดอร์เดียวกันกับไฟล์ `fpsso`**
- จากนั้นให้ลูกค้ารีสตาร์ทเซอร์วิสด้วยคำสั่ง:
  ```bash
  sudo systemctl restart fpsso
  ```

ระบบจะอ่านไฟล์ `license.key` และกลับมาทำงานได้ตามปกติทันทีครับ
